## Critical Anti-Patterns

| Pattern | Description | Prevention |
|---|---|---|
| `gh run download` без маски | Скачивание спотыкается о dockerbuild-артефакт и не забирает ничего | Скачивать поимённо: `-n acceptance-<distro>-<model>` для каждого элемента |
| Второй `--trace` в `walk_check` | `run_level` уже передаёт свой `--trace`; дубль даёт «error» на каждом повторе | Запись идёт через `run_level(..., keep=<путь>)`, а не через хвост аргументов |
| `git add -A` из корня | В корне неотслеживаемые остатки v1 | Стейджить явными путями |
| Прямой вывод адреса origin | Исторически URL содержал токен | `sed -E 's#https?://[^ ]+#<remote-hidden>#g'`, `gh` только с `--repo hzname/robot-dog` |
