Параметры: `--ref REF` (обязателен при запуске), `-f key=value` (повторяемый вход workflow), `--wait-job SUBSTR` (повторяемый: ждать только заданий, в имени которых есть подстрока; без него ждать весь запуск), `--download DIR` (скачать артефакты запуска в DIR), `--run-id ID` (не запускать, а только ждать и скачивать уже идущий запуск), `--timeout-min N` (по умолчанию 120), `--poll-sec N` (по умолчанию 30), `--dry-run` (печатать планируемые команды `gh`, ничего не выполняя, в виде `gh workflow run ci.yml --repo hzname/robot-dog --ref <REF> [-f key=value ...]` при запуске и `gh run view <ID> --repo hzname/robot-dog --json jobs ...` при ожидании, в режиме `--run-id` команда `gh workflow run` не печатается), `--help`.
