## Флаги допущений и отклонений

- **Константа 0x0999 в RESEARCH и outline: опечатка.** Шунт 10 мОм по формуле RESEARCH (PG /2 = 0x0800, BADC = 0x0180, SADC = 0x0018, MODE = 0x0007) даёт 0x099F: у 0x0999 нижние три бита 001 задают однократное преобразование шунта без шины, отсчёты застыли бы после первого чтения. Имя `kIna219Fast80mv` сохранено, значение 0x099F, тест разбирает поля по битам. Планам 01-09, 01-12, 01-14 и README ссылаться на константу по имени.
- **Адреса 0x41..0x4F, а не «любой кроме 0x40».** Адреса вызова всех PCA9685 (0x70..0x74) опаснее 0x40, поэтому допустимы только адреса INA219 по A0/A1 без 0x40; значения `power.yaml` (0x41, 0x44, 0x45) проходят. **Шунты 0.1 и 0.01 Ом (±5 %):** остальные отвергаются, а не угадываются (код 2).
- **Добавки к именам контракта (аддитивно):** `I2cBus::read8` и `writeBytes` (для PCA9685 в плане 01-09), API `FakeI2cBus`, поля `samples`, `bus_volts`, `shunt_raw_min`, `shunt_raw_max` в `SelftestResult`, `ina::isSafeAddress`, `ina::fullScaleShuntVolts`, `ina::kPca9685Address`; тестов в `Ina219Fast` шесть вместо двух именованных в outline, в `Selftest` пять вместо четырёх.
- **Семантика:** интервал измеряется между началами тиков, пауза считается от начала тика; `kSelftestMinSamples = 100` нужен, чтобы p99 имел смысл; вердикт FAIL даёт код 1 (CI и скрипты читают код); `--help` печатает справку в stdout с кодом 0 (в `pca9685_probe` справка только при ошибке, код 2). Пороги 1.5 мс и 5 мс заданы outline и не пересматриваются. Ссылка `docs/REVIEW.md:27` дана как «item 12»: номер строки плывёт.
- **Задача 1 трогает 7 файлов** (два шаблонные: `package.xml`, `CMakeLists.txt`); три задачи зафиксированы outline. Каждая задача оставляет пакет собираемым: `CMakeLists.txt` растёт вместе с исходниками. **Трассер:** по outline весь план трассер потока S2, внутри порядок снизу вверх вынужден зависимостями компиляции, сквозной путь замыкает задача 3 типа `tracer`.
