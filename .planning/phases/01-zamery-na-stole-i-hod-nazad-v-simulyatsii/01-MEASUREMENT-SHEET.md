# Лист замеров: стол и скорость серв (Phase 1)

Лист заполняет владелец, числа уходят в `robot.yaml` и `servos.yaml` через `tools/robot_setup`.
**Все работы части 1 — при обесточенных сервах** (питание шины серв выключено); питание включается только в части 2.

## Как пользоваться

**Инструменты (D-19):** штангенциркуль, кухонные весы до 5 кг (точность 1 г), транспортир или угольник, мультиметр.

**Правило «между центрами осей»:** все размеры — между центрами осей, а не до краёв деталей. Ось сервы — центр её вала, ось подшипника — центр отверстия. Штангенциркулем удобно мерить между винтами-осями и прибавлять диаметр одного винта: половина с одной стороны плюс половина с другой.

**Допуски:** длины ±1 мм; размеры корпуса ±5 мм; `body_com_x` ±3 мм; массы ±1 г; углы ±1° (ориентир).

**Формат ответа в чат:** строками `идентификатор = значение`. Пример (не замер):

```
thigh = 105
calf = 104
body_com_x = -6
```

**Дальше — Claude (D-26):** числа из чата вносятся через `python3 tools/robot_setup/robot_setup.py --cli`, проверяются `--check` и `walk_check` в CI, изменения коммитятся в ветку фазы. Группы «Датчики» и «Восприятие» не заполнять: этих датчиков на роботе нет. Высоты стойки (`stand_height`, `lie_height`, `min_height`, `max_height`) не мерятся — они задаются так, чтобы колено в стойке было согнуто на 60–100°.

## Часть 1. Стол (CAL-16)

### Шаг 1.0. Сверка схемы ноги (D-22): СТОП при несовпадении

Сначала сверьте ногу робота с моделью v2. Любое расхождение — **СТОП**: остальное не заполнять, в `--cli` не вводить, написать в чат. Кинематику и схему ноги молча не меняем; полная проверка `calib_pose 15 0 -90` остаётся за Phase 7.

| Вопрос | Как проверить | Ожидается | Ответ |
|---|---|---|---|
| Ось hip идёт вдоль корпуса (нога отводится вбок)? | Смотреть на робота сзади: ось сервы hip параллельна длине корпуса, качалка уводит ногу вбок | да | |
| Три сустава на ногу? | На ногу три сервы: hip (отведение), thigh (бедро), calf (колено) | да | |
| Колено сгибается назад? | Смотреть сбоку (левый бок, «вперёд» → вправо): колено выступает назад | да | |
| Разница высот осей hip и thigh не больше 5 мм? | В модели оси отведения и бедра на одной высоте; приложить линейку или уровень к обеим осям | до 5 мм | |
| Знаки углов совпадают со схемами? | hip «+» — стопа влево (у левых наружу, у правых внутрь); thigh «+» — стопа назад; calf «−» — колено назад | да | |

### 1.4 Пределы суставов

Сервы без питания. Рукой довести сустав до упора (в корпус, в соседнее звено, в тягу), записать угол транспортиром по знакам со схем и **отступить 5°**. Для hip — отдельно «наружу» и «внутрь»: форма сама развернёт знаки для правых ног.

| Поле (`id`) и подпись в `robot_setup --cli` | Ед. | Значение | Как мерить | Ключ YAML | Схема |
|---|---|---|---|---|---|
| `hip_out` — hip: наружу от вертикали | ° | | левая нога — влево, правая — вправо; до упора минус 5° | `servos.yaml` `min_deg`/`max_deg` (hip), `description.hip_limits_deg` | [measure_leg_rear.svg](../../../docs/img/measure_leg_rear.svg) |
| `hip_in` — hip: внутрь (под корпус) | ° | | до упора минус 5° | `servos.yaml` `min_deg`/`max_deg` (hip), `description.hip_limits_deg` | [measure_leg_rear.svg](../../../docs/img/measure_leg_rear.svg) |
| `thigh_min` — thigh: минимум (стопа вперёд) | ° | | углы по схеме «нога сбоку»; до упора минус 5° | `servos.yaml` `min_deg`/`max_deg` (thigh), `description.thigh_limits_deg` | [measure_leg_side.svg](../../../docs/img/measure_leg_side.svg) |

### 1.5 Тяга колена

В v2 тяга только на колене и опирается на бедро (серва колена стоит на бедре у оси бедра, связанных суставов нет, `coupled_to` не нужен); суставы hip и thigh сидят прямо на валу сервы (D-20). Все четыре длины — между центрами осей и шарниров, достаточно одной ноги, если ноги одинаковы. **Питание серв в части 1 не включать:** серва на центральном импульсе `pca9685_probe pulse <канал> 1370` и перпендикулярность её рычага проверяются после части 2 (когда питание включается).

| Поле (`id`) и подпись в `robot_setup --cli` | Ед. | Значение | Как мерить | Ключ YAML | Схема |
|---|---|---|---|---|---|
| `calf_servo_arm_mm` — calf: рычаг сервы | мм | | на центральном импульсе рычаг сервы перпендикулярен линии «ось сервы — ось сустава» | `servos.yaml`, строка `*_calf_joint`: `servo_arm_mm` | [measure_linkage.svg](../../../docs/img/measure_linkage.svg) |
| `calf_joint_arm_mm` — calf: рычаг сустава (0 = как у сервы) | мм | | 0 = рычаг сустава такой же, как у сервы | `servos.yaml`, строка `*_calf_joint`: `joint_arm_mm` | [measure_linkage.svg](../../../docs/img/measure_linkage.svg) |
| `calf_rod_mm` — calf: тяга (0 = как расстояние между осями) | мм | | 0 = тяга равна расстоянию между осями | `servos.yaml`, строка `*_calf_joint`: `rod_mm` | [measure_linkage.svg](../../../docs/img/measure_linkage.svg) |
| `calf_axis_distance_mm` — calf: ось сервы ↔ ось сустава | мм | | между центрами оси сервы и оси сустава | `servos.yaml`, строка `*_calf_joint`: `axis_distance_mm` | [measure_linkage.svg](../../../docs/img/measure_linkage.svg) |
| `calf_coupled` — Тяга колена опирается на корпус (серва колена в блоке бедра) | 0/1 | | у v2 — нет: тяга опирается на бедро, значение 0 | `servos.yaml`: `coupled_to` не нужен | [measure_linkage.svg](../../../docs/img/measure_linkage.svg) |

Отдельная строка, которую в `--cli` не вводят: восемь полей `hip_servo_arm_mm`, `hip_joint_arm_mm`, `hip_rod_mm`, `hip_axis_distance_mm`, `thigh_servo_arm_mm`, `thigh_joint_arm_mm`, `thigh_rod_mm`, `thigh_axis_distance_mm` = 0 (hip и thigh на валу сервы, D-20).
