## Trust Boundaries

| Boundary | Description |
|---|---|
| рабочая машина → GitHub | push и вызовы `gh`; адрес origin в логи не печатать |
| `ci.yml` → раннер | `friction`/`payload_mass` идут через `env:`, не через `inputs.*` в `run:` |
| мир и URDF → все последующие замеры | умолчания обязаны совпадать с прежними байт в байт, иначе база фазы 1 несравнима |
