    ros2_ws/src/dog_bringup/config/robot.yaml,

  </files>
  <action>
    1. `LocomotionParams`: `tilt_soft_deg{15.0}`, `tilt_stop_deg{20.0}` рядом с `slope_max_deg`.
       Валидация при построении: `0 < soft < stop <= 45`, иначе исключение с числами (как у
       остальных параметров).
    2. `LocomotionController`: приватный `tiltScale()` — при `slope_valid_` берёт
       `tilt = max(|slope_pitch_|, |slope_roll_|)` в градусах; `tilt <= soft` → 1.0;
       `tilt >= stop` → 0.0; между — `(stop - tilt) / (stop - soft)`. Без валидной оценки — 1.0.
       Геттер `double tiltScale() const` для тестов и телеметрии.
    3. `update()`: сразу после сборки `target` (перед ограничением ускорения) умножить `vx`, `vy`,
       `wz` на масштаб. Нулевая команда в WALK у существующего контроллера означает «стоять на
       месте» — отдельного переключения режима не требуется, и это проверяется тестом.
    4. `robot.yaml`: блок `tilt:` с `soft_deg: 15.0` и `stop_deg: 20.0` и комментарием-источником;
       `locomotion_node.cpp` объявляет `tilt.soft_deg` / `tilt.stop_deg` рядом с `slope.max_deg`.
    5. Тесты `test_locomotion.cpp`: масштаб 1.0 без IMU; 1.0 при 14.9°; 0.5 при 17.5°; 0.0 при 20°;
       наклон вбок считается так же, как вперёд; twist на выходе действительно уменьшен (не только
       геттер); при 20° робот не шагает (`velocity()` нулевая, `gait().stepping()` ложь после
       нескольких тактов); отказ при `soft >= stop` и при `stop <= 0`.
  </action>

## Trust Boundaries

| Boundary | Description |
|---|---|
| IMU → контроллер | оценка уклона фильтруется (τ = 0.8 с) и принимается только в STAND/WALK и до `slope_max_deg` |
| параметры → поведение | пороги приходят из `robot.yaml`; сторож контракта сверяет их с умолчаниями кода |
| замер → вывод | числа берутся из JSON и sim-лога скриптом, не на глаз |

## STRIDE (кратко)

| ID | Категория | Компонент | Мера |
|---|---|---|---|
| T-02-02-01 | Tampering | пороги в YAML | сторож 01-15 сверяет набор ключей и значения; расхождение красит job |
| T-02-02-02 | Denial of Service | ходьба на склоне | губернатор только снижает скорость; аварийные ворота и `slope_max_deg` не меняются |
| T-02-02-03 | Repudiation | замер | `git_sha` в JSON и `RUN_ID` в отчёте |
