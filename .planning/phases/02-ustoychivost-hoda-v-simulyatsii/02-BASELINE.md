# 02-01: базовая линия до правок

Замеры сняты на коде, где поведение походки не менялось: только входы трения и груза.
Уклон — `5ae88da` (единственное отличие от следующих прогонов: `payload_mass: 0.0` в
`robot.yaml`, на физику не влияет), остальные три — `259f9df`.

```text
code_sha: 259f9df (уклон — 5ae88da)
run_slope: 40505952461 (terrain, slope 7 и 10, mu=1.0)
run_slip: 40508787100 (acceptance, flat_A_bwd10, mu=0.6)
run_payload: 40511294102 (+0.296 кг), 40512322041 (−0.296 кг)
```

## 1. Спуск задним ходом по уклону 7° и 10° (`mu = 1.0`)

`terrain_sweep --terrain slope --levels 7,10`, все 16 проверок PASS на обоих углах.

| Манёвр | 7°: доля / наклон / увод | 10°: доля / наклон / увод |
|---|---|---|
| forward | 0.82 / 7.6° / −2.6° | 0.83 / 8.6° / +0.7° |
| left | 0.62 / 6.5° / −1.3° | 0.62 / 6.7° / −2.3° |
| right | 0.65 / 6.1° / −0.2° | 0.60 / 8.2° / +0.1° |
| turn_ccw | 1.25 / 6.2° / +71.2° | 1.20 / 5.2° / +69.6° |
| turn_cw | 1.16 / 7.2° / −78.2° | 1.20 / 7.5° / −77.3° |
| **backward** | **0.70 / 10.7° / −4.3°** | **0.68 / 12.0° / −3.4°** |

Спуск назад уже проходит с запасом: 70 % и 68 % команды при воротах 40 %, наклон 10.7° и 12.0°
при воротах 20°, падений нет. То есть GAIT-03 на текущей походке выполняется — возиться с ним
в волнах 2–4 не придётся, если только возмущения не сломают именно эту ячейку.

## 2. Скользкий пол `mu = 0.6` (`flat_A_bwd10`, 5 повторов)

| Элемент | n | падения | min % | медиана % | max увод, ° | вердикт |
|---|---|---|---|---|---|---|
| Jazzy real | 5 | 0 | 67.9 | 70.2 | 5.8 | PASS |
| Jazzy ideal | 5 | 0 | 57.5 | 66.9 | 4.0 | PASS |
| Lyrical real | 5 | 0 | 53.8 | 59.3 | 11.6 | PASS |
| Lyrical ideal | 5 | 0 | 50.6 | 60.3 | 8.5 | PASS |

Для сравнения, на штатном полу (`mu = 1.0`, приёмка фазы 1): Jazzy real min 46.9 %, медиана 57.7 %,
увод 6.1°.

Скользкий пол **не ломает** ход и даже увеличивает долю команды: на трении 0.6 стопы проскальзывают
по направлению движения, и корпус проходит больше за тот же шаг. Плата — увод на Lyrical real
11.6° против 7.1° в приёмке фазы 1 (эта ячейка по уводу не гейтится, но в отчёте фазы 4 это число
стоит держать в виду).

## 3. Груз на корпусе ±20 % (`flat_A_bwd10`, 5 повторов)

| Элемент | +0.296 кг: min / медиана / увод | −0.296 кг: min / медиана / увод |
|---|---|---|
| Jazzy real | 59.6 / 65.8 / 5.1° | 46.4 / 62.8 / 6.1° |
| Jazzy ideal | 58.6 / 70.1 / 4.2° | 50.8 / 57.1 / 6.0° |
| Lyrical real | 46.3 / 63.2 / 4.5° | **40.6** / 57.4 / 5.0° |
| Lyrical ideal | 46.8 / 69.8 / 4.7° | 42.2 / 58.1 / 5.4° |

Падений нет ни в одном повторе. Тяжёлый корпус проходит лучше лёгкого — это ожидаемо: больше
сцепления, стопы меньше скользят. Самый слабый угол базы — **облегчённый корпус** (Lyrical real
min 40.6 % при воротах 40 %, то есть впритык).

## Что это значит для волн 2–4

1. Ни одно из трёх возмущений по отдельности ход не валит. Значит, зачёт GAIT-05 будет решаться
   не отдельными параметрами, а их комбинацией — как и решено (D-02: каждый отдельно плюс
   комбинация худших).
2. Худший угол по дистанции — лёгкий корпус (−20 %), а не тяжёлый. В комбинацию «худших» надо
   брать именно его, а не по привычке «тяжелее = хуже».
3. GAIT-03 (спуск 7–10° назад) на чистом полу уже выполняется; настоящая проверка будет в
   комбинации со скользким полом и медленными сервами.
4. Мягкий порог наклона (волна 2) на этой базе ничем не подпирается: наклон при спуске 10° —
   12.0°, до 15° ещё есть запас. Порог 15°/20° выбран владельцем из доменных соображений, и данные
   ему не противоречат.
