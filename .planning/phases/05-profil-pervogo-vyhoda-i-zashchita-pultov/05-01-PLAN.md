# 05-01: профиль «пол» одним аргументом (CAL-07, TEL-04, TEL-06)

**Волна**: 1. **Зависит от**: —

## Задачи

1. `ros2_ws/src/dog_bringup/dog_bringup/profile.py` — чистый Python без rclpy: `overrides(name)` возвращает
   словари параметров по узлам (`locomotion`, `joy_teleop`, `web_teleop`) и флаги (`web_drive`,
   `allow_calibration`). `floor` — скорость 0.05 м/с (`max_vx 0.10` при `normal_scale 0.5`), turbo
   выключен, IMU обязателен, компенсация и удержание курса выключены; `bench` — текущие значения.
2. `robot.launch.py`: аргумент `profile` (default `bench`), значения из `profile.overrides()` подставляются
   последними в списки параметров узлов; `web_teleop` получает `allow_calibration` и `drive_enabled`.
3. `joy_teleop_node`/`mapping`: параметр `turbo_scale` (по умолчанию 1.0); в `floor` — 0.5, то есть turbo
   не даёт больше обычного.
4. `locomotion_node`: латчированный публикатор `profile` (`std_msgs/String`); `keyboard_teleop` подписан,
   при `floor` печатает отказ и не публикует команды (D-13).
5. `docs/CONTROL.md`: раздел «Профиль первого выхода на пол».

## Проверка

`python3 -m pytest ros2_ws/src/dog_bringup/test/test_profile.py` (без rclpy): числа профиля, что `floor`
строже `bench` по каждой ручке, что `floor` требует IMU и выключает веб-управление.
`bash tools/local_gtest/run.sh dog_control locomotion` — регрессий нет.
