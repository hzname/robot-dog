# 05-02: веб не снимает аварию, калибровка по умолчанию закрыта (TEL-02)

**Волна**: 1. **Зависит от**: —

## Задачи

1. `protocol.py`: чистая функция `estop_decision(current: bool, requested: bool) -> (allowed, publish, reason)` —
   постановка разрешена всегда, снятие запрещено (D-16).
2. `web_teleop.py`: `allow_calibration` по умолчанию **false**; E-STOP проходит через `estop_decision`;
   при отказе клиент получает `{"type":"error","message":"..."}`.
3. `web_teleop.py`: параметр `drive_enabled` (default true) — в профиле «пол» выключен: сообщения движения
   отклоняются с причиной, страница получает признак «только просмотр».
4. Страница: в режиме просмотра кнопки движения и E-STOP заблокированы, видна подпись «профиль: пол».

## Проверка

`pytest ros2_ws/src/dog_web/test/test_protocol.py` — новые кейсы `estop_decision` (4) и разбор режима
просмотра; `pytest test_alarm.py`.
