# 05-02: веб не снимает аварию, калибровка закрыта — сводка волны

## Что сделано

1. **`protocol.estop_decision(current, requested)`** — чистая функция: разрешены обе стороны (D-16,
   уточнено владельцем), публикация только при изменении состояния, чтобы повтор сообщения не сыпал в
   топик.
2. **`protocol.gate_actions(...)`** — режим просмотра: отбрасывает привод, команды и позу; нулевой
   twist, который несёт сообщение об E-STOP, не считается попыткой ехать.
3. **`allow_calibration` по умолчанию `false`**; открывается только аргументом `calibrate:=true` и
   никогда — профилем «пол».
4. **`drive_enabled`** и флаг `view_only` в сообщении состояния: страница блокирует управление и
   показывает «профиль «пол»: только просмотр».
5. **Тест mock bringup** ставит и снимает аварию со страницы — как это делает оператор.
