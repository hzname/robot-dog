# 05-03: WebSocket — Origin, число клиентов, простой (TEL-03)

**Волна**: 2. **Зависит от**: 05-02 (общий файл страницы).

## Задачи

1. `wsserver.py`: `Server(..., max_clients=4, idle_timeout=60.0, check_origin=True)`.
   - `Origin` (если пришёл) должен совпадать с `Host` по хосту; иначе `403`. Без `Origin` — пропускать
     (инструмент калибровки ходит не из браузера).
   - Число одновременных WebSocket-клиентов ограничено; сверх лимита — `503` и закрытие.
   - Простаивающее соединение (ни одного кадра дольше `idle_timeout`) закрывается кодом 1001.
2. `web_teleop.py`: значения лимитов — параметрами (`max_clients`, `idle_timeout`).

## Проверка

`pytest ros2_ws/src/dog_web/test/test_wsserver.py`: совпадающий `Origin` → 101; чужой → 403; сверх
лимита → 503; простой при `idle_timeout=0.3` → соединение закрыто.
