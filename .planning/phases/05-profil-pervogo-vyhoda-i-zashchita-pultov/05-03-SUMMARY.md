## Что сделано

1. **`Origin` против `Host`**: браузерная страница может открыть сокет только с того хоста, с которого
   её отдали; запрос без `Origin` (curl, инструмент калибровки) пропускается. Несовпадение — `403`.
2. **Лимит одновременных сессий** (`max_clients`, по умолчанию 4): сверх лимита — `503` и закрытие.
3. **Простой** (`idle_timeout`, по умолчанию 60 с): молчащую сессию сервер закрывает кодом 1001.
4. **Страница шлёт `ping`** раз в 25 с, иначе вкладка-наблюдатель закрывалась бы каждую минуту;
   сервер `ping` игнорирует (тип добавлен в протокол).
