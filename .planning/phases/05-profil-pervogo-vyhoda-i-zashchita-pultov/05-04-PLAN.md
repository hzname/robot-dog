# 05-04: ступенька калибровки и файл-надстройка (CAL-04, CAL-05)

**Волна**: 3. **Зависит от**: —

## Задачи

1. `ServoDriver::setCalibration` (или обёртка в узле): если канал включён и ступенька пульса для текущей
   цели больше `calibration.max_live_step_deg` (по умолчанию 10°), изменение отклоняется с причиной
   `live calibration would jump 14 deg (limit 10): move the joint or disarm first` (D-17).
2. `robot.launch.py`: если рядом с `servos.yaml` есть `servos.local.yaml` — он идёт вторым файлом
   параметров (перекрывает базовый). Путь печатается в лог запуска.
3. `.gitignore`: `**/servos.local.yaml`; `robot_setup` пишет результат калибровки в него и печатает
   команду тега `robot-calibrated-<дата>` (D-14).
4. `docs/DEPLOYMENT.md`: раздел про надстройку и тег.

## Проверка

gtest `dog_hardware servo_driver` — новый набор `LiveCalibrationTest` (ступенька отклонена, малая принята,
разоружённый канал принимает любую); pytest контракта YAML — `servos.local.yaml` не попадает в git
(проверка `git check-ignore`).
