# 06-02: запись bag одной командой (CAL-10) — ЗАКРЫТ 2026-10-29

## Что должно быть

Одна команда запускает запись со стандартным списком топиков, одинаковым для каждого
выхода на пол.

## Что сделано

- `ros2 launch dog_bringup record.launch.py` (или `... out:=/tmp/bags`): `ros2 bag record`
  с фиксированным `TOPICS`, zstd, каталог `~/dog-bags/<дата-время>` на каждый запуск.
- Список: состояние и команды (`state`, `command`, `estop`, `cmd_vel`), суставы
  (`joint_states`, `joint_commands`, `servo_pulses`), `guard`, `imu/data`, `power`, `joy`,
  `body_pose`, `profile`, `terrain/profile`.
- `ros2_ws/src/dog_bringup/test/test_record.py` (5): имена с префиксом `/dog/`, без
  дубликатов, каждое имя встречается в исходниках (переименование ломает тест), набор для
  разбора падения на месте, каталог на запуск уникален. Тест подключён к сборке
  (`ament_add_pytest_test`) и к быстрой python-джобе.

## Грабли

- `/dog/odom` в список не попал осознанно: локомоушен публикует его только при
  `odom.publish`, и в обычном прогоне на роботе его может не быть; при разборе падения
  достаточно `joint_commands` и `servo_pulses`.
