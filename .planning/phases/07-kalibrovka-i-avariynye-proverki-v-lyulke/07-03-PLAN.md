# 07-03: калибровка 12 серв в люльке (CAL-01, CAL-03) — ОТКРЫТ, стенд

Порядок — `docs/DEPLOYMENT.md`, стадии 5–8, по одному go/no-go на стадию:

1. Сервы по одной, без качалок, центр 1370 мкс.
2. Качалки только на 1370 мкс в монтажную позу hip 0° / thigh +45° / calf −90°, затем качка ±20°.
3. Опорная поза `calib_pose 0 0 –90` по угольнику; направления: `15 0 –90` — все стопы влево,
   `0 20 –90` — назад, `0 0 –60` — колени разгибаются.
4. Нули `offset_deg` с точностью ≈1°.
5. Пределы `min_deg`/`max_deg` малыми шагами (`--find-limits` только от лабораторного блока с
   ограничением тока).
6. Запись в `servos.local.yaml` и `robot_setup --check` (проверки симметрии и края пульса уже
   в инструменте).
7. Независимая перепроверка камерой (`tools/autocal`), расхождение > 2° разобрать до записи.
8. Тег `robot-calibrated-<дата>`.

Начало каждой стадии — только после «готов» владельца.
