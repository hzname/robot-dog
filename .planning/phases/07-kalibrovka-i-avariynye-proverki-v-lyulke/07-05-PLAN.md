# 07-05: настоящий Bluetooth-геймпад (TEL-05) — ОТКРЫТ, стенд

Проверки, каждая — с записью:

1. Отключение геймпада на ходу: `joy` пропадает → таймаут `cmd_vel` → робот стоит.
2. Переподключение: геймпад снова управляет без перезапуска стека.
3. Залипшие оси: стик зажат при потере связи → после переподключения команда не продолжается
   сама.
4. Снятие E-STOP только с геймпада — и на странице (страница теперь тоже снимает).

Это проверка, а не разработка: код таймаутов и защёлок готов.
