# 07-05: настоящий Bluetooth-геймпад (TEL-05) — ОТКРЫТ, стенд

Проверки, каждая — с записью:

1. Отключение геймпада на ходу: `joy` пропадает → таймаут `cmd_vel` → робот стоит.
2. Переподключение: геймпад снова управляет без перезапуска стека.
3. Залипшие оси: стик зажат при потере связи → после переподключения команда не продолжается
   сама.
4. Снятие E-STOP только с геймпада — и на странице (страница теперь тоже снимает).

Это проверка, а не разработка: код таймаутов и защёлок готов.

## Что уже сделано без железа

`tools/joy_replay` подменяет пульт: пять сценариев (едем, потеря связи, возврат с
центрированным стиком, возврат с зажатым стиком без гашетки, возврат с зажатыми стиком и
гашеткой), приговор по каждой фазе по фактическому `/dog/cmd_vel`. Прогон на мок-стеке —
13 из 13 (2026-10-29). Для этого в запуск добавлен `gamepad_reader:=false`: joy_teleop
работает, чтение `/dev/input/js*` выключено.

Предел честный и записан в сценарий: если пульт вернулся с зажатыми стиком и гашеткой,
робот поедет — программно это неотличимо от намерения оператора.

На железе остаётся радиоканал: спаривание, потеря Bluetooth на ходу, переподключение с
другими индексами осей у конкретного пульта.
