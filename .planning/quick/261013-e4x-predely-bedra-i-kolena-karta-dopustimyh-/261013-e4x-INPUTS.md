## 2. Главный результат

Механизм колена: серва колена стоит в блоке бедра (на корпусе) и тянет голень через двойной параллелограмм
(кривошип 24.0 → тяга 28.2 → диск на оси бедра, плечи 23.9/26.9 → тяга 100.0 → рычаг голени 27.0, бедро 100.1).
Абсолютный угол голени равен углу сервы колена 1:1. Поэтому:

- q1 — бедро (URDF: 0 = бедро вниз, «+» стопа назад), q2 — колено относительно бедра (отрицательное = колено назад);
- s = q1 + q2 — абсолютный угол голени, его и задаёт серва колена (`coupling: 1.0`).

**Область без столкновений в осях (q2, s) — прямоугольник**: 0 несовпадений из 825 клеток при q1 ∈ [0, 120]°.

| величина | граница по карте (клетки 5°) | жёсткие упоры по мелким разверткам | рекомендуемая область, запас 5° |
|---|---|---|---|
| q2, колено относительно бедра | −145 … −35 | −145.6 … −35.6 (бедро × link_100mm) | **−140 … −40** |
| s = q1 + q2, голень абсолютно | −85 … +20 | −87 … +18 (кривошип/удлинитель × диск) | **−80 … +15** |

Дополнительные упоры вне полезной области: q1 ≤ −35° (бедро × удлинитель кривошипа), q1 ≥ 150° (мёртвая точка механизма).
Самостоятельного предела у бедра нет: он выражается через q2 и s (q1 = s − q2 ∈ [−40, 155]).
Касания 2–25 мм³ (код `a`, `b` на карте) — трение бедра о диск/голень при |q2 − q2_ref| ≥ 10°, не блок.

Отведение (hip, отдельные развертки по всем четырём ногам): наружу свободно не менее +70° (касание около +78°),
внутрь упоры 39° (FL), 41° (FR), 41° (RL), 40.5° (RR). У владельца замерено `hip_out = 54`, `hip_in = 36` (уже с запасом 5°) —
совместимо, hip не менять.
