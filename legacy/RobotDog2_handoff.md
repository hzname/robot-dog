# RobotDog 2.0: контекст для агента

Источник: артефакт «Испытания RobotDog 2.0» из экспорта Claude (24.09.2026, 2 версии, публичный). Ветка на момент испытаний: `hzname/busy-pascal-0d7hn7`. Исходного кода и переписки в архиве нет, только отчёт с данными прогонов.

## Робот и стек
- Четвероногий робот, 12 суставов (3 на ногу: hip – отведение вбок, thigh – бедро, calf – колено). Ноги LF, RF, LR, RR.
- Сервоприводы MG996R через ШИМ-контроллер PCA9685. Под нагрузкой дают около 6 рад/с, драйвер режет выше 6 рад/с, тесты требуют пиковую скорость сустава < 5.5 рад/с.
- ROS 2: проверено на Jazzy (Gazebo Harmonic 8.11) и Lyrical (Gazebo Jetty 10.5), в официальных образах.
- Высота корпуса стоя z = 0.162 м, лёжа z = 0.092 м.

## Пакеты
| Пакет | Назначение | Тесты |
|---|---|---|
| `dog_control` | C++ ядро: кинематика, походка, режимы (stand/walk/lie/estop) | 22 gtest |
| `dog_hardware` | драйвер сервоприводов, PCA9685, калибровка | 10 gtest |
| `dog_teleop` | раскладки, клавиатура, геймпад (Xbox, через FIFO с сырыми `js_event`) | 11 gtest + 1 интеграционный |
| `dog_web` | веб-пульт: JSON-протокол поверх собственного WebSocket-сервера (RFC 6455) | 15 pytest |
| `dog_description` | URDF, сверка с формулами контроллера, доп. настройки Gazebo | 3 pytest |
| `dog_bringup` | запуск всего стека в режиме mock | 2 интеграционных |
| `dog_gazebo` | симуляция, проверка ходьбы `ros2 run dog_gazebo walk_check` | – |

## Что гарантируют тесты (64 кейса, `colcon test`)
- **Походка:** при duty > 0.5 есть фаза опоры на все 4 ноги; диагональные пары шагают вместе; на месте шагов нет; длина шага ограничена; при повороте на месте стопы идут по касательной; остановка с возвратом стоп в нейтраль; перенос непрерывен.
- **Кинематика:** нулевые углы – нога висит вертикально; соглашения о знаках; стойка симметрична, колено назад; прямая и обратная задачи сходятся по всей рабочей зоне; недостижимые цели ограничиваются с флагом.
- **Режимы:** пассивен до команды stand; скорость ограничена и сглажена по темпу; lie во время ходьбы сначала дошагивает; e-stop переводит в пассив и блокирует команды; неизвестные команды отклоняются; скорости суставов укладываются в возможности сервоприводов.
- **Драйвер:** маппинг угол ↔ импульс с ограничением по пределам сустава и серво; поэтапное включение питания; ограничение скорости изменения (slew rate); e-stop отключает выходы; игнор нечисловых значений; калибровка на лету.
- **Телеуправление:** без deadman движения нет; турбо; мёртвая зона; кнопки срабатывают по фронту; e-stop сильнее deadman; таймаут останавливает только при движении.
- **Веб-протокол:** drive масштабируется и ограничивается; stop и estop обнуляют twist; лимиты позы; любые битые сообщения дают только ошибку; watchdog срабатывает один раз при зависании клиента.

**Результат:** 64/64 на Jazzy (12.5 с) и 64/64 на Lyrical (11.1 с).

## Прогон в Gazebo (`walk_check`)
Сценарий: встать → по 5 с вперёд (0.12 м/с), назад (−0.10), влево (0.06), вправо (−0.06), поворот ↺ и ↻ (±0.5 рад/с) → лечь. Манёвр засчитывается при > 40 % от команды, наклоне корпуса < 20° и без падения. Все 8 шагов пройдены на обоих дистрибутивах.

| Манёвр | Jazzy | Lyrical |
|---|---|---|
| вперёд | 108 % (0.65 м) | 105 % (0.63 м) |
| назад | 74 % | **51 %**, увод по рысканию −15° |
| влево | 84 % | 79 % |
| вправо | 85 % | 70 % |
| поворот ↺ | 80 % (+114°) | 77 % (+111°) |
| поворот ↻ | 79 % (−113°) | 83 % (−118°) |
| макс. наклон | ≤ 6° | ≤ 8° |

Слабое место: ход назад и боковой ход, особенно на Lyrical/Jetty. При боковом ходе и ходе назад заметен увод по рысканию (до 10–15°).

## Параметры походки (выбранные)
Рысь с фазами опоры на 4 ноги: период **0.55 с**, опора **65 %**, высота шага **20 мм**, макс. шаг **0.06 м**. Фазы опоры на 4 ноги убрали раскачку, которая была у чистой рыси (T 0.5, duty 0.5, h 30 мм: назад −14 %, наклон 19°).

Как подбирали. Сетка период 0.4–0.6 × опора 60/65/70 % × высота 20/25 мм, критерий – пиковая скорость сустава < 5.5 рад/с. Выбранная точка даёт 5.08 рад/с. Затем кандидатов проверили в Gazebo:

| T, с | опора | h, мм | пик, рад/с | вперёд | назад | влево | наклон |
|---|---|---|---|---|---|---|---|
| 0.5 | 50 % | 30 | – | 103 % | −14 % | ушёл вперёд | 19° |
| 0.4 | 65 % | 25 | 8.0 (сервы не тянут) | 89 % | 81 % | 81 % | 9° |
| 0.5 | 60 % | 20 | 4.65 | 86 % | 35 % | 57 % | 11° |
| **0.55** | **65 %** | **20** | **5.08** | 102–113 % | 75–92 % | 80–91 % | 8° |

Пиковые скорости на предельных командах, рад/с (hip / thigh / calf):

| Команда | hip | thigh | calf |
|---|---|---|---|
| вперёд 0.15 | 0 | 3.96 | 4.43 |
| назад 0.15 | 0 | 3.99 | 4.43 |
| вбок 0.08 | 1.84 | 2.26 | 4.52 |
| поворот 0.6 | 1.23 | 2.73 | 4.45 |
| всё сразу | 3.05 | 4.23 | **5.08** |

Узкое место – колено (calf).
