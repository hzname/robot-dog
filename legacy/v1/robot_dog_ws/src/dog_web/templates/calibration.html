🔧 Калибровка нуля

Установите offset для каждого сустава, чтобы команда 0° соответствовала реальному нейтральному положению. Шаг: 0.5° за нажатие.

⚠️ Калибровка границ суставов

Найдите физические пределы каждого сустава. Двигайте шаг за шагом (0.5°), пока рычаг не упрётся. Нажмите кнопку фиксации — система автоматически отступит 1° для безопасного запаса.
