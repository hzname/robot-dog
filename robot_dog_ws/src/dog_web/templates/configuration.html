Суставы — шаблоны лимитов

📐 Соглашение о знаках (положительное / отрицательное)
Тип Ось + (положительное) − (отрицательное)
HIP Roll (отведение) Нога наружу ↗ Нога внутрь ↙
THIGH Pitch (наклон) Бедро назад ↩ Бедро вперёд ↪
CALF Pitch (колено) Колено разгибается ⌒ Колено сгибается ⌒⁻¹

⚠ Для правых ног (RF, RR) флаг inverted=true зеркально отражает команду сервы: положительная команда → физическое движение в обратную сторону.

Лимиты применяются ко всем суставам данного типа (hip/thigh/calf). Neutral для calf должен совпадать с nominal_calf_angle.

📋 Список суставов и инверсия

Инверсия (inverted) нужна для правых ног (RF, RR) — сервы установлены зеркально. inverted=true → команда умножается на −1.

Высота подъёма стопы в фазе переноса, мм.
Множитель длины шага относительно скорости. Больше = шире шаг.
Коэффициент связи угловой скорости с боковым смещением стоп.

Балансировка (PID)

⚠ Робот встанет в configured pose. Баланс использует текущие PID коэффициенты.
Roll (крен)
Пропорциональный коэффициент по крену. Реакция на отклонение roll.
Интегральный коэффициент по крену. Накапливает ошибку, устраняет статический перекос.
Дифференциальный коэффициент по крену. Гасит колебания, демпфирование.
Pitch (тангаж)
Пропорциональный коэффициент по тангажу. Реакция на наклон вперёд/назад.
Интегральный коэффициент по тангажу. Компенсирует постоянный наклон.
Дифференциальный коэффициент по тангажу. Гасит колебания корпуса.
Height (высота)
Пропорциональный коэффициент по высоте. Поддерживает заданную высоту стойки.
Интегральный коэффициент по высоте. Компенсирует проседание под нагрузкой.
Дифференциальный коэффициент по высоте. Гасит вертикальные колебания (пружина).
Лимиты
Максимальная коррекция крена. Ограничивает компенсирующий наклон.
Максимальная коррекция тангажа. Ограничивает компенсирующий наклон.
Максимальная коррекция высоты. Предотвращает чрезмерное проседание/подъём.
Максимальная скорость изменения коррекции, рад/с. Сглаживает реакцию.
Ограничение целевой позы. Команды наклона выше этого значения обрезаются.

IMU (MPU6050)

Показывает текущие roll/pitch/yaw. Проверяет связь с датчиком.
Путь к I2C-шине, например /dev/i2c-0. На Banana Pi обычно /dev/i2c-3.
I2C-адрес MPU6050 (104 = 0x68 по умолчанию, 105 = 0x69 если AD0=HIGH).
Частота публикации данных IMU в ROS2, Гц. Должна быть ≤ частота опроса датчика.
Mahony Filter
Пропорциональный коэффициент фильтра Махони. Больше = быстрее отслеживание, больше шум.
Интегральный коэффициент фильтра Махони. Устраняет дрейф гироскопа. Обычно << Kp.
Вес акселерометра в комплементарном фильтре. 0.98 = 98% гироскоп, 2% аксель.
Если данных нет дольше этого времени, IMU считается отключённым.

Драйвер сервоприводов

Показывает количество найденных сервоприводов и их текущие позиции.
Тип шины. simulation = без железа, i2c = PCA9685, uart = UART-сервы.
Путь к устройству. Для I2C: /dev/i2c-3, для UART: /dev/ttyS2.
I2C-адрес PCA9685 (64 = 0x40 по умолчанию).
Частота ШИМ для серв, Гц. Стандарт: 50 Гц (период 20 мс).
Если команд нет дольше этого времени, сервы обесточиваются (безопасность).
Максимальное изменение позиции за один цикл. Ограничивает скорость сервы (безопасность).
Частота обновления позиций серв, Гц. Обычно 50–100 Гц.
Плавная интерполяция между целевыми позициями. true = мягкие движения.
Время интерполяции между текущей и целевой позицией, секунды.
