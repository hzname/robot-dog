# Автокалибровка по камере (`robotdog_autocal`)

Программа запускается на ноутбуке с камерой и сама находит для каждой сервы `direction`, `offset_deg` и реальный масштаб импульса. По желанию она находит и механические упоры. Камера следит за бумажными ArUco-метками на осях суставов, а программа двигает сервы через веб-страницу робота. **ROS на ноутбуке не нужен**, подходят Windows, macOS и Linux.

## Установка

```bash
cd tools/autocal
python3 -m pip install -r requirements.txt     # numpy + opencv-contrib-python
python3 -m robotdog_autocal demo               # проверка без железа: виртуальный робот
```

`demo` запускает всю процедуру на виртуальном роботе со скрытыми ошибками калибровки. Виртуальная камера рисует его метки. В конце программа печатает найденные и истинные значения. Ошибка должна быть около 1° или меньше.

## 1. Метки

```bash
python3 -m robotdog_autocal markers --marker-mm 25       # robotdog_markers.png, A4
```

Печатайте в масштабе 100 % и проверьте линейкой, что чёрный квадрат ровно 25 мм. **Центр метки ставится на ось сустава** (по рискам вокруг метки). Как метка повёрнута, неважно: программа использует только положения центров.

| Вид | Метки |
|---|---|
| **спереди** | 20 ось hip LF (на передней стенке корпуса), 21 стопа LF, 22 ось hip RF, 23 стопа RF |
| **сзади** | 24 ось hip LR, 25 стопа LR, 26 ось hip RR, 27 стопа RR |
| **слева** | 0 ось бедра LF (снаружи, на валу сервы thigh), 1 ось колена LF, 2 стопа LF, 3–5 то же для LR |
| **справа** | 10–12 для RF, 13–15 для RR |

Метки на стопах должны смотреть в камеру для своего вида: сбоку — наружу, спереди и сзади — вперёд или назад. Удобно клеить их на маленькие флажки из картона.

## 2. Камера (необязательно, но точнее)

```bash
python3 -m robotdog_autocal camera-calib --camera 0 --square-mm 25
```

Покажите камере шахматную доску (9×6 внутренних углов), сделайте 10–20 снимков с разных сторон (ПРОБЕЛ), затем нажмите ENTER. Результат сохраняется в `camera.json`. Без этого шага фокусное расстояние оценивается по углу обзора (`--hfov 65`), и точность немного падает.

## 3. Проверка кадра

```bash
python3 -m robotdog_autocal preview --camera 0 --view left --intrinsics camera.json
```

Все метки вида должны быть обведены зелёным, поверх кадра показаны измеренные углы. Камеру ставьте в 40–60 см, **обе ноги целиком в кадре с запасом**: во время калибровки стопы уходят на ±20°. Камера должна смотреть примерно перпендикулярно борту.

## 4. Калибровка

Робот стоит на подставке, ноги висят свободно. Стек запущен (`docker compose up -d`), робот не стоит на ногах, то есть в режиме «выключен».

```bash
python3 -m robotdog_autocal run --robot 192.168.1.50 --camera 0 --intrinsics camera.json \
    --view all --apply --servos-yaml ../../ros2_ws/src/dog_bringup/config/servos.yaml
```

- **Порядок видов: спереди, сзади, слева, справа.** Программа попросит перенести камеру. Сначала калибруются hip: пока hip не выставлен, плоскость ноги наклонена, и это исказит вид сбоку.
- Каждая серва проходит 9 положений в пределах ±20° от опорной позы. По ним строится прямая «импульс → угол» (для тяги — модель четырёхзвенника). После применения программа проверяет результат повторным измерением.
- По умолчанию делается 2 прохода: второй уточняет результат после первого.
- **Ctrl-C сразу обесточивает сервы** (E-STOP). Снять его можно на веб-странице.
- Без `--apply` робот не изменяется (пробный прогон), результат пишется только в `servos_calibrated.yaml`.
- `--find-limits`: после калибровки каждый сустав медленно уводится за текущие пределы, пока не перестанет следовать за командой (упор или столкновение) или пока не подскочит ток (если стоит датчик тока). Новый предел ставится с запасом 3°.

## Точность

| Источник | Величина |
|---|---|
| Метка 25 мм с 50 см | ≈ 0.3–0.5 мм по положению |
| Угол звена 105 мм | ≈ 0.5–1° |
| Проверка на виртуальном роботе | ошибка нуля ≤ 1.1°, проверка поз ≤ 2.6° (3 набора скрытых ошибок) |
| Люфт MG996R | 1–2° |

## Как это устроено

| Модуль | Что делает |
|---|---|
| `client.py` | WebSocket-клиент к каналу калибровки `web_teleop` (`cal_hello`, `cal_pose`, `cal_set`, поток `cal_status` с импульсами и током) |
| `vision.py` | поиск ArUco (OpenCV 4.6–5.x), 3D-положение метки через `solvePnP` |
| `geometry.py` | углы из положений меток; поперечная ось корпуса берётся из плоскостей ног, поэтому наклон камеры не искажает вид сбоку |
| `servo_model.py` | та же модель «импульс ↔ угол», что в драйвере, включая тяги (проверяется по контрольным значениям C++) |
| `fit.py`, `procedure.py` | качание суставов, подгонка, проверка, поиск упоров, запись `servos.yaml` |
| `sim.py` | виртуальный робот и камера для тестов и `demo` |

Тесты: `python3 -m pytest tests` (26 тестов, в том числе полный прогон на виртуальном роботе).
