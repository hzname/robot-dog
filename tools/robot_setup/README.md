# robot_setup — ввод измеренных параметров робота

Инструмент для этапа 1 из [docs/DEPLOYMENT.md](../../docs/DEPLOYMENT.md). Замеры вводятся в форму, проверяются и сохраняются в `ros2_ws/src/dog_bringup/config/robot.yaml` и `servos.yaml`. Нужны Python 3.8+ и PyYAML (`pip install pyyaml`), ROS не нужен.

```bash
python3 tools/robot_setup/robot_setup.py            # форма в браузере: http://localhost:8765
python3 tools/robot_setup/robot_setup.py --cli      # текстовый режим (например, по SSH на роботе)
python3 tools/robot_setup/robot_setup.py --check    # проверить текущие файлы (так же делает CI)
python3 tools/robot_setup/robot_setup.py --config /путь/к/config   # другая папка с конфигами
```

## Что вводится

Рядом с каждой группой полей в форме показана схема из `docs/img`: как и от чего мерить.

| Группа | Поля | Куда пишется |
|---|---|---|
| Нога | `thigh`, `calf`, `hip_offset` (мм), направление колена | `robot.yaml` → `geometry` |
| Корпус | `hip_x`, `hip_y`, размеры корпуса, радиус стопы (мм) | `geometry`, `description` |
| Стойка | высота стойки, «лёжа», минимум и максимум (мм) | `stance` |
| Массы | корпус, звенья одной ноги (г); общий вес — только для сверки | `description` |
| Пределы суставов | hip наружу и внутрь, thigh и calf (°) | `servos.yaml` → `min_deg`/`max_deg` всех ног (для правых ног hip зеркалится); `robot.yaml` → `*_limits_deg` |
| Тяги | рычаги, тяга, расстояние между осями (мм); колено от корпуса | `servos.yaml` → `servo_arm_mm` и др., `coupled_to` |
| Датчики | есть / нет; положение (мм) и углы (°) лидаров «крестом», GS2 и четырёх VL53L1X (FL, FR, FC, RC) от центра корпуса | `robot.yaml` → `sensors` (для ToF — элементы списков `tof_x` … `tof_yaw_deg`) |
| Восприятие | порог лидаров, поправки ToF с ровного пола (мм), реакция на препятствия: вкл./выкл., дистанция остановки, самый высокий уступ и самый высокий шаг | `robot.yaml` → `perception` |

## Что проверяется

Если есть ошибки, форма не сохраняет.
- Высота стойки, «лёжа», минимум и максимум достижимы для ноги длиной `thigh + calf`.
- Углы бедра и колена в стойке попадают в пределы суставов.
- Колено в стойке согнуто на 60–100°.
- Тяга замыкается на центральном импульсе.
- Сумма масс отличается от веса на весах не больше чем на 8 %.
- Датчики в стойке: GS2 достаёт до пола (дальность 300 мм), его линия лежит перед стопами и накрывает обе линии стоп; луч каждого ToF попадает на пол ближе 1 м, пятна FL/FR — на линиях стоп; крест лидаров лежит на полу впереди, ближе 1.2 м. Где именно всё это ложится на пол, форма показывает в сообщениях.

## Как сохраняется

- Меняются только значения. Комментарии и выравнивание в файлах остаются.
- Если значение не изменилось, строка не трогается.
- Предыдущая версия каждого файла сохраняется как `*.bak` (эти копии не попадают в git).
- После сохранения показывается разница: её удобно сверить перед коммитом.
